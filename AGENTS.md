# OpenBoa Plugins contributor contract

- This repository is a catalog only. Do not copy plugin code, skills, MCP configuration, traces, scores, or support tables here.
- Keep every source selector exact and reviewable. A catalog entry must identify the plugin name, repository URL, full commit SHA, install policy, and category.
- Keep the Hydra `0.0.0` entry `NOT_AVAILABLE` until its reviewed source revision and fresh-install checks exist.
- Link to Hydra and Hydra Eval for source, support, and evidence instead of duplicating their data.
- Use the Codex marketplace format and validate JSON before committing. A client login is not permission to make an entry available.
